浏览器语音识别（网页版替代 Paraformer）

生图直连 Ark 可能被浏览器 CORS 拦截（原生 App 没有这个问题）。若生图失败，改用「选本地图片」：先在别处生好图再传上来裁剪；或用 README 里的局域网后端代理形态。

③ 裁剪预览（1200×1600）

流程要点（网上版）：手机流量下生图 → 下载裁剪后 JPEG → 连板子 AP ePaper-13in3 → 打开板子自带页面 http://192.168.4.1 选文件上传。若本页由板子同源 serve，历史里的图片可直接推图。

④ 推图到板子

依次尝试：原始 JPEG → multipart 字段 file → multipart 字段 image

网上版（https）点推图会被浏览器拦截：https 页面不允许访问 http://192.168.4.1。请先用上面「下载裁剪后 JPEG」，再连板子 AP，用板子自带页面上传。本页由板子同源 serve（http://192.168.4.1）时，点推图即可。

关于本页与 APK 的对应关系

生图模型：doubao-seedream-5-0-flash-260915，接口 ark.cn-beijing.volces.com/api/v3/images/generations；裁剪目标 1200×1600；推图 POST /upload，状态 GET /status。板子固件源码已证实 /upload 是原始 JPEG body（.ino 注释写明必须用 server.raw() 收字节）；本页仍按「原始 JPEG → multipart file → multipart image」顺序自动尝试作兜底，并在日志里写明哪一种成功。
